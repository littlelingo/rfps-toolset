# Questions to the Agency - {title}

Living document. The questions window is the one time the agency will answer in writing for every bidder, so use it to remove ambiguity before pricing, to steer a requirement toward a strength without saying so, and to learn what the evaluators care about. Rows are updated in place by stable ID (Q-01, ...), never renumbered. Status is Draft, Sent, Answered or Dropped. Do not put a `|` character inside a cell. The tools draft questions for you to send; they never send anything. `/rfps:refresh-reports` flags a question not sent as the deadline nears, and the worklist ranks it.

Write each question so every bidder could read it without learning our strategy. Cite the solicitation section it is about. When an answer arrives, quote it in the Answer column, then record it in `amendments/log.md` (it can change a requirement) and put the log number in "Logged as".
